# Ink Ops

A one-map, one-on-one browser FPS drawn in ink. M4, pistol and knife against an AI rival in a small town.

**Play:** https://securetheatlas.github.io/Ops/

## Controls

| Key | Action |
|---|---|
| W A S D | Move |
| Mouse | Aim · left click fires · right click aims down sights |
| 1 / 2 / 3 / wheel | M4 · Pistol · Knife |
| R | Reload |
| V | Quick knife |
| Shift | Sprint |
| C | Crouch |
| Space | Jump |
| Esc | Pause |

## Running it

The whole game is a single `index.html`. It loads three.js r128 from cdnjs and two Google Fonts; everything else is inline. Open the file in a browser or serve it from GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/ (root)`).
